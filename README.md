# Harf FC

Appli pour apprendre l'arabe en jouant, sur iPad (thème foot).

- Code : `src/` (React + TypeScript + Vite)
- Appli prête à l'emploi : `docs/index.html` (publiée avec GitHub Pages)
- Construire : `npm install` puis `npm run build`, puis copier `dist/index.html` dans `docs/`.
